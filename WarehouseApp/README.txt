Группа: 9ИС-445  
Стиль кода: Google C++ Style Guide

Цель и задача
Закрепить навыки ООП, работы со STL, файлового ввода-вывода и проектирования модульных приложений на C++. Задача - создать консольное приложение для автоматизации учёта товаров.

Технические требования
- Язык: C++17
- Хранение данных: 'std::vector`
- Формат файла: TXT с разделителем `,`
- Обработка ошибок: реализована через циклы `while` и очистку потока `cin`.

Инструкция по установке и запуску
1. Клонируйте репозиторий: `git clone <ссылка>`
2. Перейдите в папку: `cd WarehouseApp`
3. Создайте папку `data` и пустой файл `products.txt` внутри неё.
4. Скомпилируйте проект: `g++ main.cpp Warehouse.cpp -o app`
5. Запустите: `./app` (или `app.exe` в Windows).

Структура проекта
main.cpp - точка входа, меню, настройка консоли.
Warehouse.cpp - вся бизнес-логика, работа с файлами, аналитика.
Product.h - описание структуры товара.
data/products.txt - файл для хранения данных.

Комментарии по проекту
В процессе выполнения я столкнулся с трудностью при парсинге текстового файла — сначала пытался использовать `sscanf`, но потом перешел на `stringstream`, так как с ним проще работать со строками. Также произошла ошибка с очисткой буфера `cin.ignore()`, чтобы кириллица и ввод чисел не конфликтовали.
